# 候補モデル一覧

> 2026-11-27 時点の整理。**記載内容は未検証**で、Phase 1以降で実機確認し、結果をここへ反映する。
> 配布元・ライセンス・対応状況は導入前に必ず一次情報で確認すること。

## A. 物理モデル（数値予報モデル）

| モデル | 概要 | Mac(arm64)での見込み | 備考 |
|---|---|---|---|
| WRF（ARW） | 領域気象モデルの標準。 | ビルド可の報告あり。gfortran・netCDF等の整備が必要 | 情報が最も多い。まず本命 |
| SCALE-RM | 日本発の領域モデル（理研）。 | ビルド可否は要確認 | 日本語資料が多い |
| CM1 | 雲解像の理想実験向け。 | 小規模なら軽い見込み | 理想実験の入門向き |
| MPAS-A | 全球・可変解像度。 | 重い見込み。粗解像度のみ | 後回し |

## B. AIモデル（データ駆動予報）

| モデル | 概要 | Mac(arm64)での見込み | 備考 |
|---|---|---|---|
| ECMWF AIFS（ai-models経由） | ECMWFのオープンな機械学習予報。 | 推論のみ。PyTorch/MPS or CPUで要確認 | 初期値はECMWFオープンデータ |
| GraphCast | DeepMind。GraphCast_small等 | JAX。CPUでは遅い見込み | 重み・ライセンス要確認 |
| Pangu-Weather | ONNX推論 | ONNX Runtime(CPU)で動く見込み | ライセンスが非商用系。要確認 |
| FourCastNet 系 | NVIDIA系 | PyTorch。要確認 | |
| NeuralGCM | ハイブリッド（物理+学習） | JAX。要確認 | |

## 進め方（案）

1. **AI**: AIFS か Pangu-Weather から1つ → 全球・粗解像度・数日先の推論
2. **物理**: WRF の理想実験（組み込みケース）→ 実事例（沖縄周辺・小領域）
3. **比較**: 同じ初期時刻・同じ領域で降水・気圧・風を並べる
