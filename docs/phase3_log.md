# Phase 3 作業ログ — AIFS と WRF の比較、ローカルWebアプリ

2026-11-27。事例: 初期 2026-11-26 18UTC、沖縄周辺（北緯22〜30度・東経122〜133度）、予報24時間。

## 比較の方法

- 参照は **ECMWF IFS（HRES・オープンデータ、同じ初期時刻の予報）**。00UTC（27日）の解析値は公開前だったため、まず「モデル間の差」を見る形にした。**IFS は真値ではない**。解析値・アメダス実況での検証は公開後に追加する
- 比較は WRF の格子（121×101・内部のみ、境界10格子を除外）上。AIFS・IFS は 0.25° から双線形補間
- 対象: 海面気圧・2m気温・10m風速・6時間降水。WRF の海面気圧は簡易の海面更正（PSFC・T2・標高から）
- 比較するモデル: AIFS（手元・CPU）、AIFS（ECMWF公式の同初期時刻）、WRF（GFS初期値）
- スクリプト: [compare/compare_wrf_aifs.py](../compare/compare_wrf_aifs.py)（表と図）、[compare/fetch_reference.py](../compare/fetch_reference.py)（IFS・公式AIFS取得）。Webアプリの検証表・RMSE図も同じ計算

## 結果（IFS 比。偏差 / RMSE / 相関）

| 海面気圧 hPa（+6h） | +0.26 / 0.40 / 0.89 | +0.50 / 0.55 / 0.93 | +0.50 / 0.66 / 0.78 |
| 海面気圧 hPa（+24h） | +0.10 / 0.21 / 1.00 | -0.00 / 0.14 / 1.00 | +0.67 / 0.73 / 0.99 |
| 2m気温 ℃（+6h） | +0.04 / 0.34 / 0.98 | -0.02 / 0.34 / 0.98 | +0.04 / 0.64 / 0.93 |
| 2m気温 ℃（+24h） | +0.21 / 0.34 / 0.99 | +0.07 / 0.25 / 0.99 | -0.02 / 0.41 / 0.98 |
| 10m風速 m/s（+6h） | -0.62 / 1.24 / 0.89 | -0.70 / 1.13 / 0.92 | -0.23 / 2.09 / 0.71 |
| 10m風速 m/s（+24h） | +0.07 / 0.77 / 0.93 | +0.02 / 0.75 / 0.93 | +0.13 / 1.28 / 0.88 |
| 6時間降水 mm（+6h） | +0.25 / 5.49 / 0.84 | +0.24 / 5.40 / 0.84 | +0.20 / 13.69 / 0.46 |

24時間積算降水（領域内）: IFS 平均 11.2mm・最大 108mm／AIFS（手元）12.5・44／AIFS（公式）12.2・51／**WRF 15.1・215**。

## 読み取り（暫定）

1. **手元のAIFSは公式AIFSとほぼ同じ**（どの要素もRMSEが近い）。Phase 1のMac実行が公式を再現している裏付け
2. **WRF は AIFS より IFS から離れる**（気圧・風・降水で RMSE が大きい）。ただし 9km の WRF は細かい構造を持つので、0.25° の IFS を参照にすると「離れる」ほうが有利になりにくい点に注意（風・降水は特に）
3. **WRF の降水は領域平均で IFS より約35%多く、最大は約2倍（215mm対108mm）**。+6hの6時間降水RMSEが 13.7mm と大きく、時間とともに下がる（4.1mm）ので、**スピンアップの過大**が有力。積雲スキーム（Kain-Fritsch）の初期の暴走か、GFS初期値の水蒸気・雲の初期化の影響を疑う。対策の候補（未実施）: 積雲スキームの変更、最初の6時間を除外して評価、初期時刻の見直し
4. 海面気圧は WRF が +0.4〜0.8hPa 高め。簡易の海面更正の影響の可能性もある

## ローカルWebアプリ

計算の実行と結果の表示ができる、nwp_chart_web に似た形式のアプリ（[webapp/](../webapp/)）。

```bash
bash webapp/start.sh          # → http://127.0.0.1:8795/
```

| 機能 | 内容 |
|---|---|
| 表示 | モデル（WRF・AIFS手元・AIFS公式・IFS）、初期値、地域（沖縄周辺・東アジア）、図種タブ、予報時間スライダー・再生・←→キー、サムネイル（同時刻の他の図種）、**2モデル比較**（左右）、画像の保存、URLに状態を保存 |
| 図種 | 海面気圧・10m風、2m気温、10m風速、6時間降水、積算降水、IFS比の差（気圧・気温・風速・6時間降水）、検証（RMSE） |
| 計算の実行 | 「計算を実行」→ 初期時刻を選び、AIFS・WRF を選んで実行。参照データ取得 → GFS取得 → AIFS → WRF → 作図 を順に実行。済みの段階は自動スキップ、ログ・進行表示・中止ボタン付き。「作図だけやり直す」 |
| 検証表 | IFS 比の偏差・RMSE・相関、24時間積算降水 |

仕組み: 標準ライブラリのサーバー（`server.py`・127.0.0.1専用・Hostヘッダ検査・パストラバーサル対策）＋ Vanilla JS（`web/`）。計算は既存スクリプト（`compare/fetch_reference.py`・`physics/fetch_gfs.py`・`ai/run_aifs.py`・`physics/run_case.sh`）を子プロセスで実行し、図は `render.py`（matplotlib・950×760）が `webapp/output/<初期時刻>/<地域>/<モデル>/<図種>/f<時間>.png` に出す。1ジョブずつ（AIFSがメモリ約55GB）。

## 天気図の図種を nwp_chart_web に揃える（2026-11-27）

- nwp_chart_web の図種13種（100/200/300hPa ジェット、300・500・700・850・925hPa、500hPa高度・渦度、850hPa EPT・SSI、950hPa 水蒸気フラックス、地上 天気・SSI／気圧・風・降水）を、**同じ描画コード**（`nwp_charts.py` を `webapp/nwpcharts.py` へコピー。共通部品化しない方針）で、WRF・AIFS（手元・公式）・IFS の全部で作る
- 地域は 日本周辺・沖縄周辺・東アジア広域（nwp_chart と同じ）に、**WRF領域（9km）** を追加。WRFは WRF領域だけ
- 必要なデータの追加: IFS・公式AIFS の気圧面13面（gh・t・u・v・w と r または q）と雲量・地上気圧（各 約180〜190MB）、手元AIFSの全変数（`run_aifs.py` が 0.25度・東アジア広域に切り出して保存。1回約270MB）、WRF は気圧面（log p）へ鉛直補間して 0.1度の規則格子に変換（`webapp/fieldsF.py`）
- 注意: 950hPa 水蒸気フラックスは **WRFだけ**（IFS・AIFS のオープンデータに950hPa面がない。nwp_chart と同じ制約）。WRFの全雲量は雲水・雲氷・雪の柱の量からの近似
- 差分図（IFS比）と検証図は、図種タブの末尾（破線）に残した
- 作図は並列6プロセス。1初期時刻・背景地図2種で約1330枚・約12分・約320MB

## 背景地図（地形）

- mobile_app と同じ **国土地理院タイル**（淡色地図 pale・色別標高図 relief・陰影起伏図 hillshademap・標準地図 std）を背景にできる（`webapp/basemap.py`）。タイルは必要な範囲だけ取得して `data/tiles/` にキャッシュ。日本周辺は詳細（淡色は日本語の地名まで、色別標高図は海底地形まで）。relief・hillshade は日本の外にタイルがなく、日本の外は WPS_GEOG の標高（GMTED2010）から作った陰影起伏で補う（`terrain`）
- 塗りは透過して、下の地形を見せる。ハッチ（湿数）の透明な層は触らない（色マップの透明度を直す必要があった）
- **公開サイトには国土地理院タイルを使わない**: 利用規約（令和7年11月20日改正・公共データ利用規約 PDL1.0）は出典と**加工した旨**の記載を求めるが、事前に加工した画像の再配布が「リアルタイム読み込み」の例外に当たるか明記がなく（淡色地図・標準地図は基本測量成果）、判断できない。公開サイトの背景は GMTED2010 から自作した `terrain`。公開したい場合は国土地理院に確認し、`publish_static.py --maps pale --allow-gsi`。図には「出典: 国土地理院（…を加工して作成）」を入れてある。詳細は [NOTICE.md](../NOTICE.md)

## 任意作図アプリ（ローカル専用）

- `http://127.0.0.1:8795/custom.html`（天気図ビューアの「任意作図」から）。モデル・初期値・予報時間・**高度**・**塗り（変数・刻み・配色）**・**等値線（変数・間隔）**・**風（矢羽・矢印）**・**表示範囲（西端・東端・南端・北端の数値入力＋プリセット）**・背景地図を指定して、1枚の図を約2〜12秒（初回はデータ読込）で作る。履歴から条件を復元できる
- 高度: **気圧面 hPa**（WRFは任意の面へ直接補間。AIFS・IFSは提供13面の間を log p で線形補間し、図に注記）、**海抜高度 m**（WRFのみ）、地上（2m気温・海面気圧・10m風・降水強度・雲量）
- 変数: 気温、高度、風速、相対湿度、湿数、相対渦度、発散、鉛直p速度ω、混合比、相当温位、温位
- 投影はメルカトル（範囲200度×100度以内）。API は `POST /api/custom`（127.0.0.1専用）
- 公開サイトには載せない（ローカル専用）

## 追補（2026-11-27 夕）: 過去の初期時刻・降水の時間幅・断面図/エマグラム・画用紙版・広い地図でのWRF

- **過去の初期時刻**: ECMWF の取得を、本家（直近約3日）にあれば本家、無ければ AWS ミラーへ自動で切り替え（`compare/fetch_reference.py`・`ai/run_aifs.py` の `pick_source`）。取れる期間は IFS 約2024-02-29〜、公式AIFS 約2025-02-26〜、GFS 約2021-03-23〜。画面の「計算を実行」に日付・時刻の指定欄を追加し、範囲外・未来・00/06/12/18UTC以外は理由つきで拒否。取得は一時ファイル経由（途中で止まった不完全なファイルを取得済みと誤判定しない）
- **降水の時間幅（RR1・RR3）**: nwp_chart の描画コードが `rr_h` に元から対応。WRF は RR1・RR3・RR6、IFS は RR3・RR6（IFSの3時間間隔の地上量を別ファイル `_sfc3.grib2` で取得）、AIFS は6時間間隔のため RR6 のみ。図種タブに RR3・RR1 を追加。任意作図の地上にも「降水の幅」
- **断面図・エマグラム（任意作図）**: nwp_chart_web の `xsection.py`・`emagram.py` を取り込み、同じ形式のデータ F から作る。WRF は22の気圧面（1000〜100hPa）へ補間して使用。エマグラム（気温・露点・持ち上げ気塊・CAPE/CIN/LCL・ホドグラフ）と温位エマグラム（θ・θe・θes）
- **画用紙版**: nwp_chart_web の `board/` を、このアプリの索引（index.json）から状態を組み立てるよう調整して取り込み。ローカル（`/board/`）・公開サイトの両方にある（背景地図の選択、モデル違い・広さ違い、配置の登録）
- **広い地図でのWRF**: WRF を全地域（日本周辺・沖縄周辺・東アジア広域）で描けるようにし、データのある範囲（赤の破線の枠）だけ色を付けて、周りは背景地図のみにした。モデルの選択肢は地域によらず固定し、選んだモデルを勝手に別のモデルへ切り替えない（データが無い所は「画像なし」）
- 利用ガイド（諸元・データ・実行時間・使い方・画面例）: [guide.md](guide.md)
