    公開サイトへ反映
    
  
    GitHub Pages（インターネットに公開されるサイト）を更新します。公開するのは作図済みの画像と索引だけで、背景は標高の陰影です（国土地理院タイルの背景は公開しません）。感度実験は、WRF領域と実験の領域の図だけを載せます（容量のため）。反映後は誰でも見られます。
